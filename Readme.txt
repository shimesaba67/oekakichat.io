■しめさば帝国製 お絵描きチャット　Ver1.0.0β■

コンセプト
・P2P接続（なんらかのサーバーを介さず自分のPCやタブレットなどをサーバーにする）でお絵描きできるようにする
　オープンにしない事で仲間内だけでお絵描きを楽しむことができます。
　非公開の場ならではの絵（謎）が描けます！！（最重要！！）

できること

・ホストがレイヤー数やキャンバスサイズが変更可能
・レイヤー名もホストが変更可能
・レイヤーの順序もホストが変更可能
・ツールボックスの一番下に設定ボタンがあり、各種ツールのショートカットボタンを変更可能、その設定ファイルを保存・呼び出しできるようにしてあります


・ホストが何らかの理由で落ちた場合、お絵描き続行不能になります・・・


使用方法
・GitHubにあるホームページみたいな所のURLにアクセスしてそのまま使うことが可能
・または、GitHubにあるHTMLをダウンロードして使うことも可能　その場合は他のユーザーとバージョンが同じでなければならない
・ログイン　ホストが部屋作って　ゲストがそのホストが作った部屋のIDを教えて貰って入力すればOK
・あとは直感を信じて使ってください・・・
